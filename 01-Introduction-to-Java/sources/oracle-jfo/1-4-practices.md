Practices - Section 1 
Part 1: Create a Java Project and add an existing .java file 
Overview 
Code files for this course are supplied as .java files, which can be added to Java projects in your 
chosen IDE. 
Tasks

information on how to create a new project and add an existing .java file to the project.

Part 3: Experiment with your code 
Overview 
Make some edits to your code and observe the results. 
Tasks 
1. Edit the code so that it prints a message other than “Hello World!”. 
• Compile and run your code to verify your changes work. 
2. Change the ‘S’ in “System” to lower-case and try to compile. 
• Is Java syntax case-sensitive? 
3. Remove the semicolon (;) and try to compile. 
• Is the semicolon important to Java syntax?
