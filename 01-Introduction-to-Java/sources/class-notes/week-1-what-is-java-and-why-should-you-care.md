Time 
• Class time: 2 hours per week (practical sessions). 
• Self-study: 4to6 hours per week (practicing, reading, building). 
• Total: Approximately 6to 8 hours per week. 
Remember: Programming is a skill, like playing a sport or a musical instrument. You cannot 
learn it by watching – you must do it. 
 
➢ The Developer's Code of Conduct 
As a student in this course, you agree to: 
1. Try before asking - Read the error message, Google it, try to fix it. Then ask. 
2. Help your classmates - If you figure something out, share it. 
3. Push your code to GitHub - Every week. No exceptions. This is your portfolio. 
4. Comment your code - Write code that others (and future you) can understand. 
5. Learn from errors - Every error message is a lesson. 
6. Never copy without understanding - If you use someone's code, understand it first. 
7. Celebrate small wins - Your first program is a big deal. So is your hundredth. 
 
➢ Why This Matters for Kenya 
Kenya is the Silicon Savannah –-a hub of innovation in Africa. Companies like Safaricom, Andela, 
Twiga Foods, and countless startups are looking for skilled Java developers. 
By completing this course, you will be able to: 
• Apply for junior Java developer roles. 
• Contribute to open-source projects. 
• Build your own fintech or software startup. 
• Solve real problems in your community using technology. 
The skills you learn here are not just for passing exams. They are for building your future.
