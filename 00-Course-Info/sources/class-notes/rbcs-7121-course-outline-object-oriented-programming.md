Course Outline:   Object Oriented Programming 
Prerequisites: Introduction to Programming 
Course Code:7121 
Course Learning Outcomes 
Upon successful completion of this course, students will be able to: 
1. Design, write, and debug OOP programs that utilize fundamental programming 
constructs such as variables, control structures, loops, and functions. 
2. Apply problem-solving skills to decompose complex problems into smaller, 
manageable sub-problems that can be implemented as modular functions. 
3. Explain and implement fundamental data structures like arrays and structs, and 
demonstrate a core understanding of memory management through the use of 
pointers and dynamic memory allocation. 
4. Describe the principles of Object-Oriented Programming (OOP) and create simple 
classes and objects with member variables and methods to model real-world 
entities. 
Assessment Breakdown 
• Sitting CAT 1: 20% 
• CAT2 : 20% 
• Final Exam : 60% 
Week Java Programming Course Outline 
Week 1: Introduction to Java & Development Environment 
Topics & Subtopics: 
• History and features of Java 
• Installing JDK and setting up IDE (IntelliJ/Eclipse) 
• Writing your first Java program 
Learning Outcomes: 
1. Explain the purpose and evolution of Java. 
2. Identify key features that make Java platform-independent. 
3. Set up a Java development environment. 
4. Write and run a basic Java program.
