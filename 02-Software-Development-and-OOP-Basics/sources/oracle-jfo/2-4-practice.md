```text
Problem 2: Original ASCII Art 
 
Overview 
Using text to create a picture is known as ASCII art.  In section 2, we made an ASCII art cat.  In this 
practice, you’ll create your own beautiful work of art. 
Tasks 
1. Use print statements to create your own beautiful original ASCII art.  Use comments to 
describe what your image is depicting. 
It’s ok for your art to rely on only a single character, besides space, such as X or #.  But you’re 
encouraged to use a few different characters in your design, like in the cat example from 
class. 
2. Your art must also: 
• Use at least 8 print statements 
• Be at least 8 characters wide 
• Use at least 20 characters that aren’t space 
3. You’re welcome to create another cat.  However, this image must look significantly different 
from the example used in class.  Similarly, you’re welcome to create another face, but it must 
look significantly different from the face in the previous practice (it’s way too easy to turn 
the smiley face into a frowny face). 
Note:  The backslash (\) character has special meaning in Java print statements.  If you 
choose to use a backslash in your image, you’ll actually need to write two backslashes (\\) in 
your print statement. 
The ProblemSet2_2 project is available to help you get started.
```

```text
business continues to grow, we’re realizing this was a bad idea.  We believe it’s time for a more 
conventional and digitized approach to our operations.  Would you be able to help us develop the 
software we need to make this happen? 
Sincerely, 
President George Johnson, 
The Snake Box Factory 
 
Tasks

of creating a software solution.  Identify 3 objects from this scenario (remember, objects can

2. Write your solution as a document rather than a .java file.
```
