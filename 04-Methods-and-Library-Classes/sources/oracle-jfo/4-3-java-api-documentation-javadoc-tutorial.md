Development Kit, or JDK. 
Key Concepts • Access the Javadocs API 
• Explore Modules 
• Explore Packages, Classes, Constructors, and

Difficulty Beginner – This tutorial is appropriate for someone

Duration 30 minutes 
Notes  This tutorial was built using JDK Version 15

3. The classes are grouped by module - in this course, you will be working with classes in the 
java.base module – Select the java.base link.
